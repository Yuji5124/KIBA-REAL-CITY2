# COORDINATE_SYSTEM — 座標系・原点・単位の定義（Phase 0）

実装：`scripts/kpr_coords.py`（唯一の定義元）／テスト：`tests/test_coords.py`（**13項目すべてPASS**、2026-10-17実行）

## 1. 決定事項

| 項目 | 定義 | 理由 |
|---|---|---|
| 投影座標系 | **EPSG:6677**（JGD2011／平面直角座標系 第IX系） | 東京都の標準。既存プロジェクトと同じ |
| 緯度経度 | EPSG:6668（JGD2011）。OSMのWGS84との差は当地で0.1m未満 | |
| ローカル原点 | **E = −2302.317826321731, N = −36106.717222697174**（北緯35.67455°, 東経139.8079°） | 既存v01〜v07と同一。旧データとの比較がそのまま可能 |
| 単位 | メートル（1 Blender unit = 1 m = 1 Three.js unit） | |
| 高さの基準 | **T.P.（東京湾平均海面）の標高[m]**をそのまま使用。オフセットなし | DEM・PLATEAUとも同じ基準。公園は −2.4〜+5.8m なので精度上の問題なし |
| ローカル軸 | x = 東、y = 北、h = 標高 | |

## 2. 各ツール間の変換

```
GIS (EPSG:6677)        : (E, N, H)
ローカル               : (x, y, h) = (E − E0, N − N0, H)
Blender (Z-up)         : (x, y, z) = (x, y, h)
glTF / Three.js (Y-up) : (x, y, z) = (x, h, −y)
```

- Blender→glTF の変換は、Blender標準のglTFエクスポーター（+Y up）が自動で行うものと一致することを**実機で確認**しました（Blender 5.2.2のbpyで、頂点(10,20,3) → glTF (10,3,−20)）。
- Three.js側では **GLBに追加の回転を掛けない**。北 = −Z、東 = +X、上 = +Y。
- 回転行列の行列式は+1（右手系を維持、鏡像にならない）。

## 3. 精度の検証結果（実行ログ）

| テスト | 結果 |
|---|---|
| 原点 → (0, 0) | 誤差 0.0000m |
| 緯度経度 ⇄ ローカルの往復（公園全域＋50m余白を50m間隔で全点） | 最大誤差 0.0000mm |
| 北へ0.001° → +y 110.94m、東へ0.001° → +x 90.52m | 軸の向きが正しい |
| Three.js座標 (x, h, −n) と逆変換の往復 | 完全一致 |
| 木場公園大橋の中央点が正しい緯度経度に戻る | 35.675902, 139.808783 |
| タイル番号（負の座標を含む） | 正しい |
| float32（GPU頂点精度）で原点から700m地点 | 誤差 0.023mm（実用上問題なし） |

## 4. 公園全域の範囲（ローカル座標）

| 項目 | 西 | 南 | 東 | 北 |
|---|---|---|---|---|
| 公園境界（OSM） | −136.2 | −354.0 | 255.2 | 636.9 |
| 50m余白を含む範囲 | −186.2 | −403.9 | 305.2 | 686.9 |
| 旧モデル（500m四方） | −250 | −250 | 250 | 250 |

原点は公園の中心ではなく南寄りにあります（北端まで637m）。それでもfloat32精度は十分で、原点を変える利点より、旧データとの比較ができなくなる損失の方が大きいため、**原点は変更しません**。

## 5. ルール

1. 座標変換は必ず `kpr_coords.py` を経由する（スクリプト内に原点の数値を直接書かない）
2. Blenderオブジェクトには `kpr_crs`, `kpr_origin`, `kpr_tile`, `source_id`, `is_estimate` をカスタムプロパティで付ける（glTFのextrasとしてThree.jsに渡る）
3. GLBのノードは原則として平行移動なし（頂点にローカル座標をそのまま持たせる）。例外は樹木などインスタンス資産で、配置はJSONで管理
4. 物理演算（Rapier）も同じY-upのメートル単位を使う
5. 変換を変更したら `python tests/test_coords.py` を必ず実行する
