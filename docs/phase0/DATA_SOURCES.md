## 3. 取得手段（作業環境ごと）

| 手段 | このクラウド作業環境 | あなたのWindows PC |
|---|---|---|
| OSM API / Overpass | ❌ ネットワーク制限で接続不可 | ✅ 過去に取得実績あり |
| 国土地理院タイル | ❌ 接続不可 | ✅ 取得実績あり |
| PLATEAU カタログAPI | ❌ 接続不可 | ✅（3D Tiles配信ホストは以前ブロック） |
| npm / PyPI / GitHub | ✅ 可 | ✅ |

→ **GISデータの追加取得は、PC側でダウンロードスクリプトを実行する必要があります**（Phase 1の前提）。

## 5. 未確認・要対応

1. PLATEAU江東区2023のデータセット個別の権利表記（以前の調査でCKANがHTTP 403）
2. ODbLの「派生データベース」該当性：ゲーム用GLBを**公開**する場合は、OSM由来データの扱いを決める必要あり（ローカル利用なら問題なし）
3. 公園協会の園内マップの利用条件（トレース禁止の可能性あり）
4. 航空写真をテクスチャとして焼き込むかどうか（現時点では**焼き込まず、密度推定のみ**に使う方針）
